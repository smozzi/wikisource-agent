# Contribuer

Ouvrir une issue avant toute modification qui change un état reproductible, un format de manifeste ou une règle de publication. Préserver la compatibilité Python 3.11–3.13 et la bibliothèque standard.

Avant une proposition :

1. exécuter tous les tests et les deux validations de skills indiqués dans le README ;
2. ajouter un test pour chaque garde-fou modifié ;
3. ne jamais inclure de fac-similé, secret, chemin personnel ou identité réelle ;
4. citer une aide officielle Wikisource et sa date de vérification pour une nouvelle règle éditoriale ;
5. conserver toute écriture réseau derrière une approbation explicite.

Les changements de transcription propres à une édition appartiennent au clone de cette édition, pas au dépôt modèle.
