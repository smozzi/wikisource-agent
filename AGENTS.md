# Instructions pour les agents

Utiliser les skills du dépôt dans `.agents/skills/`. Commencer par `contribute-wikisource-fr` pour le parcours éditorial et activer `utiliser-api-wikisource` pour toute opération API ou CDP.

Exécuter `./ws check` avant de modifier un chantier. Ne jamais contourner les états, écrire sur Wikisource sans approbation explicite, lancer Chrome implicitement, versionner un secret ou traiter un script comme preuve de relecture humaine.

Conserver les identifiants `page-NNNN`, les lots bornés et les preuves avant/après. Ne créer `coordination/` que si plusieurs agents travaillent réellement sur des lots séparés.
