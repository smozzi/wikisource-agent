# Checklist Wikisource francophone

## Avant préparation

- [ ] Recherche exacte et approximative sur Wikisource et Commons
- [ ] Auteur et traducteur identifiés
- [ ] Fac-similé complet et libre retenu
- [ ] Page de titre examinée
- [ ] Droits de tous les apports éditoriaux vérifiés
- [ ] Pagination numérique → imprimée établie

## Dossier local

- [ ] `README.md` identifiant l’édition, le fac-similé et l’état du projet
- [ ] `SOURCES.md`
- [ ] `RIGHTS.md`
- [ ] `METADATA.md`
- [ ] `PROJECT_STATUS.md` daté pour un chantier repris sur plusieurs sessions
- [ ] plan Commons ou justification de l’absence d’import
- [ ] wikicode de l’index
- [ ] wikicode Auteur, page principale et transclusions
- [ ] table vues → chapitres
- [ ] OCR brut et pages corrigées séparés
- [ ] incertitudes restantes
- [ ] rapport préalable à publication

Pour un projet seulement cadré, le `README.md` peut constituer à lui seul le
dossier initial : indiquer alors explicitement que le corpus, l’OCR, la
pagination et les opérations Wikisource ne sont pas initialisés. Ne cocher les
autres éléments qu’au moment où le travail correspondant commence.

## Avant publication

- [ ] Absence de doublon revérifiée
- [ ] Nom `Livre:` identique au fichier Commons
- [ ] `<pagelist>` contrôlé
- [ ] Bornes et sections contrôlées
- [ ] Début, fin, notes et chapitres contrôlés
- [ ] Compte authentifié sur le wiki concerné
- [ ] Liste exacte des écritures approuvée

## Après publication

- [ ] Pages créées sous le bon compte
- [ ] Niveaux ProofreadPage corrects
- [ ] Transclusions sans erreur
- [ ] Fac-similé visible en mode Page/édition
- [ ] Page Auteur rendue correctement après Wikidata
- [ ] Page du traducteur mise à jour sans écrasement
- [ ] Historique et éventuels messages communautaires surveillés
